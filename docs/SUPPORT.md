# Support

BG3 Mod Manager Redux is an unofficial community project in alpha development. Support is
best-effort; compatibility with every mod, tool, game patch, or system configuration is not
guaranteed.

## Before asking for help

1. Read [Installation and updates](INSTALLATION.md) and
   [Troubleshooting](TROUBLESHOOTING.md).
2. Confirm you are using an official, complete Redux archive.
3. Search existing GitHub issues for the same behavior.
4. Reproduce the problem with the smallest safe sequence you can.

## Report a reproducible bug

Use the [GitHub bug report form](https://github.com/circleainn/BG3ModManager-Redux/issues/new?template=bug-report.yaml).
Include the Redux version, Windows version, relevant BG3 patch, expected behavior, actual behavior,
and concise reproduction steps.

Do not use a public issue to post API keys, signed URLs, saves, complete PAKs, or unreviewed logs.
See [Privacy and local data](PRIVACY_AND_DATA.md).

## Feature requests

Use the [feature request form](https://github.com/circleainn/BG3ModManager-Redux/issues/new?template=feature-request.yaml).
Explain the user problem first and keep the requested outcome focused. Planned ideas are not release
commitments.

## Other projects and mod support

- Report BG3 game defects to Larian Studios.
- Report mod-specific gameplay or compatibility problems to that mod's author.
- Report Script Extender defects to its project when the failure is outside Redux's installer or
  presentation workflow.
- Report Nexus Mods or mod.io account/service problems to the relevant provider.

Redux preserves substantial BG3MM behavior, but Redux-specific reports belong in the Redux tracker
rather than LaughingLeader's upstream tracker.
