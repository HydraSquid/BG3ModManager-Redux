# Nexus description dividers

These images are the code-rendered section dividers used by the public BG3 Mod Manager Redux Nexus Mods description.

The canonical paste-ready description is [`docs/NEXUS_DESCRIPTION.bbcode`](../../NEXUS_DESCRIPTION.bbcode). Keep it evergreen: public distribution is portable-only, and the page should not name a specific Redux release.

`00-redux-header.png` is the matching top-of-page wordmark: the Redux star, white product name, and purple `Redux` accent.

- Canvas: 1400 × 100 transparent PNG
- Typography: Manrope
- Style: centered Manrope section titles between two balanced neutral hairlines
- No logo, illustration, card, glow, color accent, or section numbering
- Naming and order follow the current Nexus description sections

The editable SVG sources and deterministic renderer are maintained with the project’s external promotional source assets. Keep these public PNG paths stable because the Nexus description links to their `raw.githubusercontent.com` URLs.
