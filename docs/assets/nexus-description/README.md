# Nexus description dividers

These images are the code-rendered section dividers used by the public BG3 Mod Manager Redux Nexus Mods description.

- Canvas: 1400 × 120 transparent PNG
- Typography: Manrope
- Style: text-only editorial layout with a small context label and thin semantic rule
- No logo, illustration, card, glow, or section numbering
- Naming and order follow the current Nexus description sections

The editable SVG sources and deterministic renderer are maintained with the project’s external promotional source assets. Keep these public PNG paths stable because the Nexus description links to their `raw.githubusercontent.com` URLs.
