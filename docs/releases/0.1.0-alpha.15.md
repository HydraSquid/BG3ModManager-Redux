# BG3 Mod Manager Redux 0.1.0-alpha.15

Alpha.15 is the first public alpha of Baldur's Gate 3 Mod Manager Redux: a modern,
community-driven fork of LaughingLeader's BG3 Mod Manager focused on clear organization,
deliberate review, safer file workflows, and a cohesive customizable interface.

> [!IMPORTANT]
> This is public-alpha software. Keep independent backups of important profiles, saves, downloaded
> archives, the BG3 Mods folder, and `modsettings.lsx`. Read each review before approving a change.

## Highlights

- Organize mods with multiple categories, custom colors and icons, persistent visual separators,
  filtering, configurable columns, and a resizable selected-mod details drawer.
- Keep working edits separate from saved orders and the game. Compare orders, inspect history,
  create restore points, use bounded Undo/Redo, and preview **Sync Load Order to Game**.
- Review built-in, read-only Mod Diagnostics. Optionally enable the experimental Load Order Advisor
  and preview separator-aware organization without silent sorting.
- Intake local packages and optional Nexus Mod Manager downloads through one persistent Download
  Manager with guarded routing, Install All review, installed history, and optional retained package
  archives.
- Browse and import saves through Save Game Manager, grouped by campaign with available thumbnail
  and difficulty metadata.
- Inspect and manage a narrow catalog of reviewed Script Extender and native/root-level packages
  through Game-Directory Mod Manager with staged writes and explicit ownership.
- Personalize Redux with Dark, Light, and Parchment themes, custom themes, generated gradients,
  imported fonts and icons, text-size controls, configurable shortcuts, and Reduce Motion.
- Use conservative offline source recognition, privacy-limited contribution reports, creator
  manifests, Redux Modlists, package preflight, Quick Access, and active-file overlap inspection.

## Install

Choose one official file:

- **Setup:** run `BG3ModManager-Redux-Setup.exe` for a guided fresh installation, .NET 8 prerequisite
  help, shortcuts, and a normal Installed Apps entry. Setup downloads and verifies Redux; it is not
  an offline bundle and does not update an existing installation.
- **Portable:** extract the complete `BG3ModManager-Redux_v0.1.0-alpha.15.zip` into its own writable
  folder, then run `Redux.exe`.

Download only from the
[Redux Nexus Mods page](https://www.nexusmods.com/baldursgate3/mods/23799) or
[GitHub Releases](https://github.com/circleainn/BG3ModManager-Redux/releases). Windows 10/11 x64,
the [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0), and Baldur's Gate 3
are required. Linux, macOS, Wine, and Proton are not supported.

Read [Installation, updates, and removal](../INSTALLATION.md) before moving from a private build or
changing an existing Redux folder.

## Moving from a private alpha

1. Close BG3 and Redux and let active file operations finish.
2. Back up the complete existing Redux folder and important game/profile state.
3. Extract the complete alpha.15 portable archive over the existing folder, or make a clean
   installation and move only the user state you deliberately intend to retain.
4. Start `Redux.exe`, confirm `0.1.0-alpha.15`, and verify the selected profile and saved order before
   syncing.
5. Repair the NXM association from Download Manager if the executable location changed.

Alpha.15 no longer runs as `BG3ModManager.exe`. A manual overlay can leave the obsolete private-alpha
runtime beside Redux. After the new application works and a rollback backup exists, remove only the
old `BG3ModManager.exe`, `BG3ModManager.dll`, `BG3ModManager.deps.json`, and
`BG3ModManager.runtimeconfig.json` files. Do not delete settings, orders, downloads, logs, archives,
backups, or other unlisted content.

## Important boundaries

- Downloading, inspecting, retaining, or installing a normal PAK never silently activates, reorders,
  saves, or syncs it.
- Saving a Redux order and syncing it to the game are separate actions.
- Categories, separators, and notes are presentation data and never enter `modsettings.lsx`.
- Mod Diagnostics is read-only. Load Order Advisor is optional, experimental, and preview-first.
- Unknown source identity remains **Local**. Unknown native DLL layouts remain unmanaged.
- Game-directory layout validation is not a publisher signature, malware scan, or universal
  compatibility guarantee.
- Redux has no analytics or general-purpose telemetry. Optional network features have separate,
  documented boundaries.

## Known public-alpha limitations

- Nexus Mods uses personal API-key authentication rather than public Redux SSO.
- Provider, category, offline-recognition, and advisor coverage is incomplete by design.
- Imported fonts and custom PNG icons can vary and remain the user's licensing responsibility.
- Some mod.io author links remain limited.
- Uncommon scaling, very small windows, or unusually dense mod sets may expose visual issues.
- Clean-machine and real-world mod-set coverage will continue expanding during public alpha.
