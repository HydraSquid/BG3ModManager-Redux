# BG3 Mod Manager Redux 0.1.0-alpha.16.1

**Bring order to the chaos.**

Alpha.16.1 is a focused correction to alpha.16. It fixes a Sync recovery failure, introduces a
hotfix-aware update version contract, and makes the lightweight Setup usable for safe updates and
repairs of installations it previously registered.

> [!IMPORTANT]
> This is public-alpha software. Keep independent backups of important profiles, saves, downloaded
> archives, the BG3 Mods folder, and `modsettings.lsx`.

## Fixed

- **Sync failures no longer lock the editor.** If rebuilding a load order fails—for example while
  handling legacy separator PAK state—Redux restores Save, shortcuts, menus, and drag-and-drop
  instead of leaving the workspace disabled.
- **Setup can update Redux.** Running the newer `BG3ModManager-Redux-Setup.exe` detects its existing
  registered installation, verifies the official release, and updates only release-owned files.
- **Setup updates are transactional.** The installer backs up the files it owns, removes obsolete
  owned files, and rolls back an incomplete update. Settings, saved orders, downloads, archives,
  logs, and other user content remain untouched.
- **Hotfix versions are explicit.** Dotted builds such as `.16.1` can be ordered and verified without
  replacing the immutable alpha.16 release or calling a corrective build alpha.17.

## Install or update

- **Setup-managed installation:** close Redux, download this release's
  `BG3ModManager-Redux-Setup.exe`, and run it. The destination is locked to the registered Redux
  installation. A same-version repair is supported; downgrades are refused.
- **Portable installation:** close Redux, back up the Redux folder, then extract
  `BG3ModManager-Redux_v0.1.0-alpha.16.1.zip` over the existing portable installation.
- **New installation:** use either asset. Setup provides guided installation, shortcuts, and a
  normal Windows uninstall entry; the portable ZIP can be extracted to any dedicated writable
  folder outside the game directory.

Alpha.15 and alpha.16 cannot parse the new dotted hotfix number, so they cannot discover `.16.1`
through their in-app updater. Download Setup or the portable ZIP manually for this one transition.
Once `.16.1` is installed, later dotted hotfixes can be discovered normally.

Windows 10/11 x64, the
[.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0), and Baldur's Gate 3 are
required. Redux and Setup are not yet code-signed, so Windows or a browser may show a reputation
warning.
