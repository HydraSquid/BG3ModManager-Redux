# BG3 Mod Manager Redux 0.1.0-alpha.16.2

**Bring order to the chaos.**

Alpha.16.2 is a focused public-alpha hotfix for source identity and correction workflows. It also
moves new Redux releases to one portable ZIP shared by GitHub Releases and Nexus Mods.

> [!IMPORTANT]
> This is public-alpha software. Keep independent backups of important profiles, saves, downloaded
> archives, the BG3 Mods folder, and `modsettings.lsx`.

## Fixed

- **Nexus files keep their own names.** When one Nexus page contains several differently named
  files, Redux now shows the exact installed file name in the mod list instead of giving every file
  the shared Nexus project title. The project title remains available in source details.
- **mod.io links can be corrected manually.** The selected mod can now be linked to a mod.io page,
  changed to another page, or returned to Local. Redux validates the entered URL or numeric ID and
  asks before replacing an existing Nexus link.

## Download or update

This release has one public artifact:
`BG3ModManager-Redux_v0.1.0-alpha.16.2.zip`. GitHub Releases and Nexus Mods receive the same ZIP.

- **Update from alpha.16.1:** close Redux and use the built-in updater when offered, or extract the
  complete alpha.16.2 ZIP over the existing Redux folder.
- **New portable installation:** extract the ZIP to a dedicated writable folder outside the game
  directory, such as `C:\Modding\Redux`, then run `Redux.exe`.

Do not copy only `Redux.exe`; the full archive is one versioned application.

Windows 10/11 x64, the
[.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0), and Baldur's Gate 3 are
required. The portable executable is not code-signed, so Windows or a browser may still show a
reputation warning.
