# BG3 Mod Manager Redux 0.1.0-alpha.16.3.1

## Silent maintenance update

- Removed the generic mod.io health warning. A linked source page does not prove that a package is
  subscribed through the in-game manager or managed by Steam Cloud.
- Added support for maintenance versions such as `.16.3.1`, including updater ordering and Nexus
  publication validation.

## Distribution

Redux remains portable-only. GitHub Releases and Nexus Mods receive the same portable ZIP. This
maintenance release is published normally but intentionally does not send a Discord announcement
or role ping.
