# BG3 Mod Manager Redux 0.1.0-alpha.16.3.2

This silent maintenance update fixes separator drag feedback around Inactive Mods.

## Fixed

- Separators can no longer be dragged into Inactive Mods.
- The insertion line is cleared immediately when that pane rejects a separator drag or drop.

## Download

Redux is distributed as one portable ZIP. GitHub Releases and Nexus Mods receive the same file.
