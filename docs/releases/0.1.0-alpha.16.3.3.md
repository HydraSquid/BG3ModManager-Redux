# BG3 Mod Manager Redux 0.1.0-alpha.16.3.3

This silent maintenance update improves NXM association controls, theme labels, and Redux branding.

## Fixed

- An older Redux install or another marked NXM handler no longer leaves the reassociation button
  disabled. Redux asks before taking over and keeps the previous handler available for restoration.
- Active custom themes now show their own name in the current-theme summary.
- Download Manager guidance is shorter and less repetitive.

## Changed

- The Redux star is now a built-in theme-aware icon and replaces the generic sparkle on startup.
- The NXM reassociation button now uses the familiar Nexus source color.

## Download

Redux is distributed as one portable ZIP. GitHub Releases and Nexus Mods receive the same file.
