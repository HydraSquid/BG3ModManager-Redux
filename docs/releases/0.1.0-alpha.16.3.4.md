# BG3 Mod Manager Redux 0.1.0-alpha.16.3.4

This silent maintenance update keeps installed mods in place when updating and fixes the option to
hide the administrator warning.

## Fixed

- Updating an installed PAK through Download Manager now retains its active or inactive state and
  load-order position. New mods still enter Inactive Mods.
- **Don't show again** on the administrator warning now remains selected after restarting Redux.

## Changed

- Nexus file uploads now show a brief change summary taken from the matching GitHub release notes.

## Download

Redux is distributed as one portable ZIP. GitHub Releases and Nexus Mods receive the same file.
