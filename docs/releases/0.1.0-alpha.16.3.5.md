# BG3 Mod Manager Redux 0.1.0-alpha.16.3.5

A silent maintenance update for download/install workflows, window behavior, and save imports.

## Fixed

- Recover remembered window positions safely, including disconnected and negative-coordinate monitors.
- Prevent repeated modal close requests and dismissal flashes.
- Keep save discovery running when metadata is corrupt and separate loose saves correctly during archive imports.
- Clean up abandoned maintenance-update folders.
- Read administrator elevation from the process token and add diagnostics for unexpected warnings. The remaining reporter issue is still under investigation.

## Changed

- Start NXM downloads quietly with compact notifications for preparation, start and completion. Existing foreground preferences are respected.
- Remove routine clean-download and clean-new-mod confirmations; retain reviews for updates, replacements and packages needing attention.
- Show package progress and block conflicting actions throughout Install All.
- Preserve load-order placement on same-version reinstalls and simplify package/action descriptions.
- Use semantic Download Manager toolbar colors and consistent selector/button styling.
- Refresh update dialogs, shorten onboarding, and show GitHub release notes in a What's New window after updates.
- Prevent updated Redux copies from running together and route NXM links to the running copy.

## Known limitations

- Older executables launched after an updated copy cannot enforce the new instance guard. Close the older copy before continuing.
- Unexpected administrator warnings (#95) still need reporter diagnostics.
- GitHub release notes need network access; the What's New window remains usable offline.

## Download

One portable ZIP is distributed through GitHub Releases and Nexus Mods. Existing settings, mods, saved orders and downloads are preserved during application updates.
