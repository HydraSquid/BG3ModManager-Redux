# BG3 Mod Manager Redux 0.1.0-alpha.16.3

Status: release candidate; not yet published.

## Source recognition hotfix

- Fixed reviewed Nexus provenance winning over an incidental mod.io `PublishHandle` when Redux is
  introduced to an existing mod installation.
- Added matching Nexus and mod.io page controls, including persistent unlinking and an explicit
  **Change Source to Nexus Mods** action.
- Added reproducible VOLO catalog synchronization for Nexus and mod.io community candidates.
- Removed automatic community matches when the same exact name exists on both providers.
- Added conservative offline mod.io recognition requiring the expected UUID plus an exact package
  name, folder, or filename match.
- Added reviewed Nexus identities for UnlockLevelCurve, its 5e patch, and Immersive UI.

## Distribution

Redux remains portable-only. Publishing this candidate requires one immutable portable ZIP shared
by GitHub Releases and Nexus Mods, followed by public artifact verification and promotion of the
public-alpha update manifest.
