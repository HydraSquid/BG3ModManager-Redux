# BG3 Mod Manager Redux 0.1.0-alpha.16

**Bring order to the chaos.**

Alpha.16 is a focused hotfix for the first Redux public alpha. It keeps the alpha.15 feature set and
fixes the highest-priority startup, accessibility, and window-behavior reports from the first public
users.

> [!IMPORTANT]
> This is public-alpha software. Keep independent backups of important profiles, saves, downloaded
> archives, the BG3 Mods folder, and `modsettings.lsx`.

## Fixed

- **Welcome Setup fits laptop displays.** The first-run window is bounded to the available desktop,
  can be resized, and keeps **Save & Continue** and **Not now** reachable at common resolutions and
  Windows scaling levels.
- **Screen-reader speech has a reliable fallback.** Redux uses its bundled Tolk bridge directly and
  falls back to Windows SAPI when the optional CrossSpeak wrapper is unavailable.
- **The administrator warning is accurate and dismissible.** Redux checks the process token's real
  elevation state, shows the notice once per startup, and honors **Don't show again**.
- **Menus open in the expected direction.** Top-bar menus, toolbar dropdowns, nested submenus, and
  combo boxes prefer rightward placement while retaining automatic screen-edge fallbacks.
- **First-run windows no longer overlap.** If the initial BG3 folder picker is cancelled and Redux
  opens Preferences, Welcome Setup waits until Preferences has fully closed before appearing.
- **Release candidates are easier to verify.** Windows CI now retains matching portable and Setup
  artifacts from the tested commit.

## Install or update

- **Setup:** run `BG3ModManager-Redux-Setup.exe` for a verified guided fresh installation. Setup is
  a small web bootstrapper and downloads the current portable package from Redux's hash-verified
  public-alpha channel.
- **Portable:** extract `BG3ModManager-Redux_v0.1.0-alpha.16.zip` into its own writable folder and
  run `Redux.exe`.
- **From alpha.15:** close Redux and BG3, back up the Redux folder, then extract the complete
  alpha.16 portable archive over the existing installation. Alpha.15 shipped with automatic update
  checks disabled, so this one update must be started manually.

Windows 10/11 x64, the
[.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0), and Baldur's Gate 3 are
required. Download only from the
[Redux Nexus Mods page](https://www.nexusmods.com/baldursgate3/mods/23799) or
[GitHub Releases](https://github.com/circleainn/BG3ModManager-Redux/releases).

## Known public-alpha limitations

- Redux and Setup are not yet code-signed, so Windows or a browser may show reputation warnings.
- Nexus Mods uses personal API-key authentication while Redux SSO registration is planned.
- Provider, category, offline-recognition, advisor, scaling, and real-world mod-set coverage remains
  incomplete during public alpha.
